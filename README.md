# Addit Website

Marketing website for Addit - AI-powered call recording and transcription app.

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router (hash-based for GitHub Pages)

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

The site is automatically deployed to GitHub Pages when changes are pushed to the `main` branch.

**Live URL:** https://addit.dev

## Pages

- `/` - Landing page
- `/#/features` - Features detail page
- `/#/privacy` - Privacy Policy
- `/#/terms` - Terms of Service
